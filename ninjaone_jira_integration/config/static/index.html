🔗 NinjaOne → Jira Field Mappings

Map NinjaOne alert fields to custom Jira fields. Use this to pass severity, source type, or other alert data into Jira so automation rules or priority matrices can act on them.

⚡ JSM Value Mappings

Map NinjaOne severity or priority values to Jira Service Management option fields such as Impact, Urgency, and Severity. Jira option values are loaded automatically once an issue type is selected.
